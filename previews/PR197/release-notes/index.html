Release notes

The format is based on Keep a Changelog, and this project adheres to Semantic Versioning.

Version v1.4.0 - Unreleased

Changed

  • BoundsErrorLight is now an alias for LightBoundsError from the LightBoundsErrors.jl package, instead of being a type defined in this package. As a consequence, the properties of the exception object and the error message have changed. (#176)
  • All out-of-bounds accesses to a FixedSizeArray going through checkbounds now throw LightBoundsError, not only those indexing with a single integer; the other cases used to throw BoundsError. (#175, #176)
  • The validation of the dimensions when constructing a FixedSizeArray is now implemented with the CheckedSizeProduct.jl package. Invalid dimensions still throw an ArgumentError, but with a single error message which includes the offending shape. (#89, #90)

Fixed

  • isassigned(::FixedSizeArray, ::Int) now checks the bounds on the FixedSizeArray itself, instead of relying on the parent to do it, giving correct results also with underlying storage types which do not check bounds. (#188)
  • copy!(::FixedSizeVector, ::AbstractVector) now throws a descriptive ArgumentError when the axes of the two arrays do not match, instead of a MethodError caused by trying to call resize! on the destination. (#194, #195)

Version v1.3.0 - 2026-02-14

Changed

  • The package extensions were renamed from RandomExt and AdaptExt to FixedSizeArraysRandomExt and FixedSizeArraysAdaptExt, respectively, to avoid clashes with similarly named extensions in other packages. (#162)
  • Improved performance of iterating over a FixedSizeArray: constant propagation through iterate now allows the compiler to unroll loops over arrays with statically known size. (#158)
  • Improved performance of destructuring a FixedSizeArray with a slurping pattern (e.g. a, rest... = array), by adding a method to Base.rest. (#166)

Fixed

  • Indexing a multidimensional FixedSizeArray with a single Colon (A[:]) now always returns a vector, instead of an array with the same shape as A. (#161)
  • Fixed type inference of collect_as in Julia v1.12 and later. (#160, #172)

Version v1.2.0 - 2025-08-07

Added

  • Pkgextension with Adapt.jl, for converting other arrays to FixedSizeArray. (#149)

Version v1.1.0 - 2025-08-05

Added

  • Support for broadcasting of view of FixedSizeArrays. (#146, #147)

Version v1.0.1 - 2025-06-08

Fixed

  • rand!(A::FixedSizeArray) now returns A, instead of its parent. (#139, #140)

Version v1.0.0 - 2025-06-04

Initial release.
